Установи его, чтобы агент Sixth в VS запрашивал структуру и связи проекта локально вместо того, чтобы скармливать модели огромные массивы сырого кода при каждом запросе.

Ниже приведена пошаговая инструкция, как правильно настроить эту связку.

---

### Шаг 1. Подготовка `codebase-memory-mcp`

1. Скачайте и установите бинарный файл `codebase-memory-mcp` для вашей операционной системы ( macOS, Linux или Windows) с официальной страницы репозитория [DeusData/codebase-memory-mcp](https://github.com/DeusData/codebase-memory-mcp).
2. Запомните полный путь к исполняемому файлу (например, `/usr/local/bin/codebase-memory-mcp` или путь в папке пользователя).
3. Проинициализируйте индекс для вашего проекта, если это требуется по инструкции репозитория, чтобы сервер построил граф знаний.

---

### Шаг 2. Интеграция в настройки Sixth (`sixth_mcp_settings.json`)

Sixth хранит конфигурации всех MCP-серверов в специальном файле настроек. Вы можете отредактировать его напрямую.

#### 1. Где найти файл настроек:

* **macOS:** `~/Library/Application Support/Code/User/globalStorage/sixth.sixth-ai/settings/sixth_mcp_settings.json`
* **Windows:** `%APPDATA%\Code\User\globalStorage\sixth.sixth-ai\settings\sixth_mcp_settings.json`
* **Linux:** `~/.config/Code/User/globalStorage/sixth.sixth-ai/settings/sixth_mcp_settings.json`

*(Альтернативный вариант через UI: откройте панель Sixth в VS Code $\rightarrow$ нажмите иконку **MCP Servers** на верхней панели $\rightarrow$ выберите вкладку **Installed** $\rightarrow$ нажмите кнопку **Configure MCP Servers**, чтобы открыть файл конфигурации).*

#### 2. Добавление конфигурации:

Добавьте `codebase-memory-mcp` в блок `mcpServers` внутри файла `sixth_mcp_settings.json`. Пример конфигурации через стандартный поток ввода-вывода (`stdio`):

```json
{
  "mcpServers": {
    "codebase-memory": {
      "command": "/полный/путь/к/файлу/codebase-memory-mcp",
      "args": [],
      "disabled": false
    }
  }
}

```

> **Важно:** Замените `/полный/путь/к/файлу/codebase-memory-mcp` на реальный путь к скачанному бинарнику на вашем компьютере. Если для запуска требуются аргументы (например, указание рабочей директории), пропишите их в массиве `"args": ["--workspace", "/path/to/project"]`.

---

### Шаг 3. Перезапуск и проверка

1. Полностью перезапустите VS Code (или перезагрузите окно комбинацией `Ctrl+Shift+P` / `Cmd+Shift+P` $\rightarrow$ `Developer: Reload Window`), чтобы Sixth подхватил новый MCP-сервер.
2. Откройте панель Sixth в VS Code и убедитесь, что `codebase-memory-mcp` отображается в списке активных и подключенных серверов со статусом **Connected**.
3. Теперь при постановке задач Sixth будет автоматически обращаться к инструментам графа кода через MCP, сокращая объем передаваемого контекста и экономя ваши токены.
